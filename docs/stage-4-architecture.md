## High-Level Architecture

- **Entry Point:** `Auth0JwtAction` (extends `Action.Simple`)
- **Config:** `Auth0PlayConfig` (domain, audience)
- **Client:** `AuthClient` from `auth0-auth-java`
- **Request Info:** Extract headers and build `HttpRequestInfo`
- **Claims:** Attach `AuthenticationContext` to request attrs
- **Error Handling:** Map SDK exceptions to Play `Result`
